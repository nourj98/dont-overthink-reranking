# Don't "Overthink" Pointwise Reranking: Is Reasoning Truly Necessary? (EMNLP 2026)

Official implementation of **[Don't "Overthink" Pointwise Reranking: Is Reasoning Truly Necessary?](https://arxiv.org/abs/2505.16886)** by Nour Jedidi, Yung-Sung Chuang, James Glass, and Jimmy Lin.

This repository contains the training and evaluation code for studying explicit reasoning in pointwise LLM rerankers. It supports StandardRanker, released Rank1 models, our matched Rank1 implementation, Rank1-NoReason, self-consistency, and inverse training.
